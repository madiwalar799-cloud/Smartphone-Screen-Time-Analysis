# Smartphone Screen Time Analysis

## 1. Introduction
Smartphones have become an important part of our daily lives. People use smartphones for communication, education, entertainment, social media, and other activities.

This project, **Smartphone Screen Time Analysis**, focuses on analysing smartphone usage patterns and understanding user behaviour through data analysis and visualisation.

## 2. Project Objectives
- To analyse daily smartphone screen time.
- To understand smartphone usage behaviour.
- To study application usage patterns.
- To identify trends in smartphone usage.
- To represent data through graphs and charts.
- To gain meaningful insights from the dataset.

## 3. Dataset Description
This project uses a smartphone user behaviour dataset containing 700 records.

**Dataset File:** `smartphone_user_behavior_sample_700.csv`

The dataset is used to explore smartphone usage patterns and user behaviour.

## 4. Technologies Used

- Matplotlib
- Seaborn
- Jupyter Notebook
